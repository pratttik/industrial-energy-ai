# AI-Based Energy Consumption Forecasting and Anomaly Detection for Smart Industries

## Problem Statement
Industrial facilities consume significant energy, and unexpected changes in production conditions or equipment behaviour can cause energy waste. Manual monitoring makes it difficult to forecast consumption and detect abnormal patterns early.

## Objectives
1. Forecast hourly industrial energy consumption.
2. Detect abnormal energy-use and process patterns.
3. Compare actual energy consumption with predicted consumption.
4. Visualize findings in a Power BI dashboard.
5. Support industrial energy managers with actionable alerts.

## Scope
The project uses historical industrial energy, temperature, and production data. Python will be used for machine learning, while Power BI will be used for dashboard visualization.

## Tools
Python, Pandas, Scikit-learn, Matplotlib, Power BI, GitHub.
